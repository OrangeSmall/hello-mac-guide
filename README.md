# Hello Mac｜你的 Mac 入門工作台

給剛從 Windows 轉用 Mac 的朋友：四週課程、快捷鍵對照、iPhone 串接自我檢查、AI 提示詞與計算練習。

## 使用

正式網站：https://orangesmall.github.io/hello-mac-guide/

GitHub Pages 發布來源：`main` 分支的根目錄。入口為 `index.html`。

也可以下載 `index.html` 後，以瀏覽器開啟；所有必要樣式和程式均已內嵌，教材與主要互動不需外部資源。外部參考連結及雲端 AI 服務需要網路。

## 學習紀錄

- 完成進度、筆記與偏好只保存在目前瀏覽器的 localStorage，沒有上傳伺服器。
- 網站本身沒有登入帳號、後端資料庫或 AI API。
- 換裝置、換瀏覽器或由本地檔案轉到網站時，請先匯出進度，再於新位置匯入。
- 清除網站資料或使用無痕模式可能造成進度不保留；建議定期匯出備份。
- iPhone 串接檢查是操作自評，不會讀取裝置。
